## / principles

A few things I actually think about while writing code — not just things that sound good in a README:

- **Readability over cleverness.** Future-you deserves legible code.
- **Security isn't a feature.** It's a baseline requirement.
- **Performance matters when it matters.** Profile before optimizing.
- **Architecture is a conversation, not a decree.** Start simple, evolve intentionally.
